## Что дорабатывается

Модульные документы `16–17`, `21–25` — развёрнутые спецификации остальных модулей до уровня
полей, форм, валидаций, уведомлений, API и критериев приёмки — ещё пишутся.

Правила работы для Claude Code — в [CLAUDE.md](CLAUDE.md).

## Статус

Черновик v0.2 от 19.09.2026. Объём: функциональность эталона копируется целиком,
модули распределены по этапам R1–R3 (`docs/08-reference-inventory.md`). Контент эталона
не переносится. Детали форм, требующие доосмотра, — в §8.12.
