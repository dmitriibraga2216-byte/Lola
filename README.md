# Lola LMS

Мультитенантная платформа корпоративного обучения для линейных команд (кухня, зал, склад).
Первый тенант — Каппі. Функциональный ориентир — LMS Collaborator (полный дубль учебной части), реализация своя.

## Быстрый старт

```bash
cp .env.example .env
pnpm install
pnpm dev:up        # postgres + minio + mailpit, миграции, сид тенанта «Каппі»
pnpm dev           # http://localhost:3000
```

Вход в dev: телефон `+380661864742` (админ); для OAuth задайте `GOOGLE_CLIENT_ID/SECRET`, `ZOOM_CLIENT_ID/SECRET` и `APP_URL` в `.env` — код OTP печатается в лог сервера (`[otp:sms] … → код 123456`).
Другие сид-люди: `+380670000002` (наставник), `+380670000003` (сотрудник).
Панель оператора — `/ops`, e-mail и пароль из `.env` (`PLATFORM_ADMIN_*`).

```bash
pnpm test          # unit + integration (123) — нужны поднятые контейнеры
pnpm build && pnpm test:e2e   # Playwright, 11 сценариев (docs/06 §6.10 + чек-лист, занятие, объявление)
pnpm lint && pnpm typecheck
```

## Что готово (этапы 0–11)

| Этап | Модуль | Ключевое |
| --- | --- | --- |
| 0 | Каркас | Nuxt 3 + Nitro, Drizzle, RLS на каждой таблице с `tenant_id`, `withTenant()`, тест полноты RLS |
| 1 | Вход и люди | OTP по телефону с лимитами в БД, сессии, роли-скоупы `can()`, импорт xlsx/csv с предпросмотром, справочники, журналы |
| 2 | Контент | Курсы → версии → модули → уроки из блоков, санитизация HTML, медиа через presigned S3 + pg-boss, каталог, плеер с условиями завершения |
| 3 | Тесты | Банк вопросов (8 типов), попытка со снапшотом, ручная проверка, очередь наставника, сертификаты с публичной проверкой |
| 4 | Назначения | Конструктор аудитории, профили должностей, правила автоматизации, уведомления с тихими часами, Telegram-бот, `due.scan`, 7 отчётов с xlsx |
| 5 | База знаний | FTS + семантика, опросы (анонимные с порогом), новости с подтверждением, практикумы с критериями и SLA |
| 6 | Платформа | Панель оператора, тарифы и лимиты, impersonation, секреты AES-GCM, вебхуки с HMAC, API-токены, sync-API, SMS/e-mail |
| 7 | Развитие | Библиотека компетенций с уровнями-поведением, профили должностей, разрыв по компетенциям, ИПР с согласованием, цели с настраиваемыми статусами и протоколом, заявки на внешнее обучение и карьеру |
| 8 | Оценка | Шкалы, группы критериев, анкеты; циклы 360° с автоназначением оценщиков, анонимностью и порогом показа, калибровкой; чек-листы наблюдения с фото, критическими пунктами, планом действий и офлайн-режимом; отчёты и дисциплина проверок |
| 9 | Занятия | Расписание очных занятий и вебинаров, запись с очередью и дедлайнами, QR-отметка с 30-секундным кодом, ручная отметка, неявки, напоминания, ics, отчёты явки; комплексные тесты из нескольких тестов с весами и min_score |
| 10 | Хаб | Объявления с обязательным прочтением (модально при входе, отчёт по точкам, напоминания и эскалация), события в расписании, wiki с иерархией, историей правок и правами по веткам, публичная оргструктура, конструктор сводных отчётов с расписанием и xlsx |
| R1-долги | PDF сертификата (pdfkit + Nunito, в S3, подписанная ссылка), перекодирование видео в 720p (ffmpeg в воркере), `/metrics` Prometheus (RED, очередь, задачи, бизнес-события), `x-request-id`/trace_id в логах и ошибках, Sentry на сервере |
| 11 | Интеграции | OAuth по docs/09 (state в БД, offline+consent, только зашифрованный refresh_token, статусы «не налаштовано / не підключено / працює / мовчить»): Google Calendar для занятий, Meet и Zoom для вебинаров, посещаемость из Zoom, импорт людей из Workspace, вход через Google |

Развёртывание на своём железе — `docker/` и `Makefile` (см. [docs/26](docs/26-server-local.md), [docs/27](docs/27-gateway-public.md)).
