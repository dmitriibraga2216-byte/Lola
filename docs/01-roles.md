# Lola LMS — ТЗ. Часть 1. Роли, права, доступ

## 1.1 Модель прав

Права выдаются не ролью напрямую, а **скоупами**. Роль — именованный набор скоупов.
Роль назначается пользователю **в области видимости**: вся сеть, конкретная точка,
конкретное подразделение. Один пользователь может иметь несколько назначений ролей.

```
user ──< user_role >── role ──< role_scope >── scope
              │
              └── scope_type: tenant | org_unit | location
                  scope_id:   uuid | null (null = вся сеть)
```

Проверка доступа: `can(user, 'course.edit', { locationId })` → true, если у пользователя есть
роль со скоупом `course.edit`, назначенная на этот тенант, это подразделение или эту точку.

## 1.2 Системные роли (создаются при заведении тенанта)

| Роль | Код | Кому | Область по умолчанию |
| --- | --- | --- | --- |
| Сотрудник | `employee` | все | своя точка |
| Наставник | `mentor` | шеф, старший смены | своя точка |
| Руководитель точки | `manager` | управляющий | своя точка |
| Методист | `author` | HR, тренер | сеть |
| Администратор | `admin` | COO, владелец | сеть |
| Оператор платформы | `platform_admin` | мы | вне тенанта |

Тенант может создавать свои роли из набора скоупов. Системные роли не удаляются,
но их набор скоупов можно менять, кроме `admin` (иначе тенант заблокирует сам себя).

## 1.5 Вход и идентификация

**Основной способ — телефон + одноразовый код.**

1. Пользователь вводит номер в формате `+380XXXXXXXXX` (маска, нормализация до E.164).
2. Сервер создаёт `otp_code`: 6 цифр, срок 5 минут, хранится как хеш (argon2id).
3. Доставка: Telegram, если номер связан с ботом, иначе SMS. Канал выбирается автоматически,
   пользователю пишется, куда ушёл код.
4. Ограничения: не более 3 отправок на номер за 15 минут, не более 5 попыток ввода на код,
   после 5 — блокировка номера на 30 минут. Счётчики — в БД, не в памяти процесса.
5. Успешный ввод → сессия: `session` в БД + httpOnly, Secure, SameSite=Lax cookie,
   срок 30 дней с продлением, привязка к user-agent и подсети (мягкая: смена → ре-аутентификация).
6. Если номер найден в нескольких тенантах — экран выбора пространства.

**Резервные способы**
- Вход по e-mail + паролю (argon2id) — для методистов и администраторов; включается тенантом.
- Ссылка-приглашение с одноразовым токеном (48 часов) — для первого входа.
- Вход «от имени» (impersonation) для `platform_admin`: только с явной причиной,
  фиксируется в `audit_log`, сессия помечена, в интерфейсе — постоянная плашка.

**Выход**: удаление сессии; «выйти на всех устройствах» — удаление всех сессий пользователя.

## 1.6 Жизненный цикл сотрудника

| Статус | Что означает | Что можно |
| --- | --- | --- |
| `invited` | создан, не входил | получить приглашение повторно |
| `active` | входил, работает | всё по роли |
| `suspended` | временно отключён | вход запрещён, данные сохранены |
| `archived` | уволен | вход запрещён, результаты хранятся, из отчётов по умолчанию скрыт |

Удаление человека — только `archived` + анонимизация по запросу (см. `06-infra.md`, GDPR-раздел).
Результаты обучения при анонимизации сохраняются обезличенно: нужны для статистики курса.

## 1.7 Структура организации

```
tenant
└── org_unit (дерево: сеть → бренд → направление)
     └── location (точка: адрес, часовой пояс, руководитель)
          └── position (позиция: повар, кассир, курьер)
```

Пользователь имеет одно основное назначение `location + position` и может иметь
дополнительные (совмещение). Назначения обучения умеют адресоваться на:
человека, позицию, точку, подразделение, роль или динамический сегмент
(см. `03-modules.md`, «Назначения»).

## 1.8 Крайние случаи

- Человек сменил точку → прошлые результаты остаются за ним, новые назначения приходят
  по новой точке; в отчёте старой точки он виден до даты перевода.
- Человек уволился и вернулся → тот же `user`, статус `active`, история цела.
- Один телефон на двоих (редко, но бывает на точках) → запрещено: телефон уникален в тенанте.
  Для таких случаев — вход по e-mail или личный номер.
- Наставник проверяет сам себя → запрещено: в очередь проверки не попадают свои попытки.
