# Lola LMS — ТЗ. Часть 5. Экраны

Визуальные правила — в бренд-буке Lola (беж `#F0E7D7` фон, солнце `#FFC933` — действие,
бирюза `#2BBFAE` — прогресс и результат, коралл `#FF6B4A` — ошибка, чернила `#0C0F14` — текст;
шрифт Nunito, заголовки 900; радиусы 16–36; теней нет). Здесь — состав и поведение.

## 5.0 Навигация

Пять разделов вместо восьми у эталона. Внутри раздела группировка по задаче пользователя:
«Головне» → «Управління» → «Я перевіряю» → «Результати» → «Налаштування».
Видимость пункта определяется скоупом; счётчики (сколько на проверке, сколько новых) —
в бейджах пункта меню.

| Раздел | Пункты |
| --- | --- |
| Навчання | Моє навчання · Каталог · Призначення · Черга перевірки · Моя історія · Сертифікати |
| Контент | Курси · Уроки · Тести · Банк питань · Опитування · База знань · Новини · Категорії |
| Люди | Користувачі · Групи · Оргструктура · Імпорт · Довідники (міста, посади, рівні, підрозділи, мітки) |
| Звіти | Готовність змін · Курси · Прострочені · Атестації · Активність · Наставники · Журнали |
| Налаштування | Простір · Ролі · Сповіщення · Профілі навчання · Правила автоматизації · Інтеграції · API |

Мобильный: нижняя панель из четырёх иконок — Навчання, Каталог, Звіти (если есть скоуп), Профіль.

## 5.1 Вход

- Один экран: поле телефона с маской `+380 __ ___ __ __`, кнопка «Отримати код».
- Второй шаг: шесть ячеек кода, подпись «Код надіслали в Telegram» или «в SMS», таймер
  повторной отправки 60 секунд, ссылка «Не приходить код».
- Ошибка: «Код невірний. Залишилось 2 спроби» — текстом под ячейками, коралловым.
- Если номер в нескольких пространствах — список карточек пространств.
- Внизу — инфоблок гостевой страницы (настраивается тенантом).

## 5.2 Моє навчання (главный экран сотрудника)

- Приветствие с именем, под ним — счётчик «2 завдання · 1 з дедлайном».
- Табы: `Актуальні` · `Прострочені` · `Завершені`.
- Карточка курса: обложка 1:1 слева (или цветная плашка с буквой), название `title-l`,
  метаданные `body-s` (уроков, минут, срок), полоса прогресса, одна кнопка.
- Дедлайн ближе трёх дней — строка «Атестація до 24 вересня» коралловым, иначе приглушённым.
- Пустое состояние: «Курсів поки немає. Керівник призначить навчання» + ссылка на каталог.

## 5.3 Урок

- Шапка: название курса, «Урок 3 з 6», кнопка выхода (сохраняет позицию).
- Тело: блоки контента в одну колонку, ширина текста 60–72 знака.
- Липкий низ: кнопка «Далі» (солнечная), слева — прогресс курса тонкой полосой.
- Кнопка «Далі» неактивна, пока не выполнено условие завершения; подпись объясняет почему
  («Ще 20 секунд», «Подивись відео до кінця»).
- Видео: свой плеер, докрутка запрещена до первого полного просмотра (настройка курса).

## 5.4 Тест

- Один вопрос на экран. Сверху: «Питання 2 з 5», таймер (если есть), последние 60 секунд — коралловый.
- Варианты — блоки с границей, выбранный — бежевая подложка с рамкой чернил.
- После ответа (если `show_answers=after_question`): верный — бирюзовая подложка, неверный —
  коралловая, под ним разбор текстом. Разбор обязателен.
- Навигация: «Далі», «Пропустити» (если разрешено), карта вопросов по свайпу вниз.
- Экран результата: крупная цифра (бирюзовая при зачёте, коралловая при провале), балл,
  разбор ошибок списком, кнопка «Повторити» (если остались попытки) или «До навчання».
- Состояние «На перевірці»: цифра не показывается, вместо неё — «Наставник перевірить
  розгорнуті відповіді. Зазвичай це займає до доби».

## 5.5 Черга перевірки (наставник)

- Список: человек, курс, вопрос, давность («2 години тому»), точка.
- Фильтры: точка, курс, давность. Сортировка по давности, самые старые сверху.
- Карточка проверки: текст вопроса, эталон (если есть), ответ человека, файлы/фото,
  история его попыток. Две кнопки: «Зараховано» / «Не зараховано» + поле комментария.
- После решения — сразу следующая карточка, без возврата в список.
- Просроченные более 48 часов помечаются коралловой точкой.

## 5.6 Призначення (управление)

- Список: название, тип (вручну / автоматично / за каталогом / за профілем), автор, метки,
  создано, старт, дедлайн, сколько людей, статус.
- Создание — шаги в одном экране:
  1. **Що** — курс или программа;
  2. **Кому** — конструктор аудитории: люди, позиции, точки, подразделения, роли, сегмент;
     рядом живой счётчик «Під умову підпадає 38 людей» и ссылка «Переглянути список»;
  3. **Коли** — старт, дедлайн (дата или «14 днів з призначення»), повтор (переаттестация);
  4. **Нагадування** — за сколько дней, в какие каналы, руководителю тоже или нет;
  5. **Параметри** — обязательность, можно ли досрочно, показывать ли в каталоге.
- Отмена назначения показывает, скольких людей это затронет и что будет с начатыми.

## 5.7 Редактор курса

- Слева дерево: модули и уроки, drag-and-drop, кнопки «+ Модуль», «+ Урок».
- Справа — редактор выбранного урока: блоки, добавление через «+», перетаскивание.
- Верх: название, статус (чернетка / опубліковано), кнопки «Попередній перегляд», «Опублікувати».
- Публикация — модалка: чек-лист проверок (зелёные/красные пункты) и обязательный changelog.
- Вкладка «Налаштування курсу»: категория, обложка, теги, язык, строгий порядок уроков,
  сертификат (шаблон, срок действия), видимость в каталоге.

## 5.8 Редактор теста

Две вкладки, как в эталоне:
- **Питання** — состав: добавить из банка (фильтр по категории, метке, сложности),
  создать новый, задать вес, порядок, пометить критическим; счётчик «Кількість запитань».
- **Опис та налаштування** — описание, метки, авторы, изображение карточки, проходной балл,
  лимит времени, число попыток, перемешивание вопросов и вариантов, показ ответов,
  нужна ли ручная проверка, нужно ли очное подтверждение.

## 5.9 Люди

- Таблица: ПІБ, посада, рівень посади, місто, підрозділ, ролі, мітки, дата реєстрації,
  остання активність. Вкладки: Активні / Заблоковані / Усі.
- Карточка человека: профиль, размещения (точка + позиция, история), роли, назначенное,
  история обучения, сертификаты, сессии, кнопка «Надіслати запрошення».
- Импорт: загрузка xlsx/csv → предпросмотр с построчной валидацией → «Застосувати» →
  отчёт (создано / обновлено / ошибок) и файл ошибок.

## 5.10 Отчёты

- Единый каркас: фильтры сверху (период, точка, позиция, курс, статус), KPI-плитки,
  таблица или столбики, кнопка «Вивантажити».
- Правила графиков: максимум два цвета (бирюза — норма, солнце — ниже нормы), каждое
  значение подписано числом, сеток нет.
- Готовность смены — главный отчёт: строки = точки, колонки = позиции, в ячейке процент
  людей с пройденным обязательным; клик проваливается в список людей.

## 5.11 Настройки

- Простір: название, логотип, язык, часовой пояс, тихие часы, инфоблок входа.
- Ролі: список, редактор скоупов, кнопка «Переглянути систему як роль».
- Сповіщення: шаблоны по кодам и каналам, переменные подсказкой, предпросмотр, тест-отправка.
- Профілі навчання: позиция → список курсов со сроками (закрывает массовые назначения).
- Правила автоматизації: триггер → условие → действие, журнал срабатываний.
- Інтеграції: Telegram-бот, SMS-провайдер, вебхуки, API-токены (показ один раз при создании).

## 5.12 Состояния, которые нужно нарисовать для каждого экрана

Загрузка (скелетон, не спиннер) · пусто · ошибка сети с кнопкой «Спробувати ще раз» ·
нет прав · офлайн (баннер «Немає зв'язку, прогрес збережеться») · длинные тексты и
длинные имена · 320px ширина.

## 5.13 Разделы модулей R2–R3

Навигация растёт до восьми разделов, как в эталоне; пункт появляется, когда модуль включён
в настройках тенанта и у человека есть скоуп.

| Раздел | Пункты |
| --- | --- |
| Навчання | + Траєкторії · Очні заняття · Вебінари · Комплексні тести · Запити |
| Контент | + Практикуми · Програми · Шкали оцінки · Бейджі |
| Люди | + Функціональні керівники · Спеціальні звіти · Протокол конфліктів |
| Розвиток | Мій план · Мої цілі · Компетенції · Профілі посад · Цілі співробітників · Заявки |
| Оцінка | Процедури · Чек-листи · Завдання оцінки · Критерії · Шкали · Звіти |
| Хаб | Новини · Оголошення · Події · Wiki · Оргструктура · Форум · Чат · Магазин |
| Для роботи | Робочі задачі · Налаштування задач |
| Звіти | + Зведений звіт · Збережені звіти з розкладом |

Правила те же: одно главное действие на экран, состояние подписано словом, таблицы —
с фильтром сверху и выгрузкой, карточки на мобильном вместо таблиц.

Ключевые новые экраны:
- **Практикум**: задание, поле ответа (текст/файл/фото), история доработок, комментарии тредом.
- **Очное занятие**: карточка с датой, местом, тренером, местами; кнопка записи; QR для отметки.
- **ИПР**: цели карточками со статусами, прогресс по каждой, кнопка «Надіслати на перевірку».
- **Чек-лист смены**: пункты списком с переключателями, поле фото, итоговый процент внизу.
- **Объявление**: модальное окно при входе с кнопкой «Ознайомився» — закрывается только ею.
- **Магазин**: каталог призов, баланс баллов в шапке, история заказов.
