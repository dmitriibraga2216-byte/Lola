# Lola LMS — ТЗ. Часть 11. Ресурси, уроки, медіа

## 1. Назначение и границы

Модуль описывает учебный контент: материалы (ресурсы), их сборку в курсы, редактор,
версионирование, публикацию, работу с медиафайлами и прохождение урока учеником.

Входит: типы материалов, блоки контента, редактор, версии, публикация, медиа-пайплайн,
плеер урока, правила завершения.
Не входит: тесты (`12`), практикумы (`13`), назначения (`15`), каталог (`10`).

| `audio` | `media_id`, `title` | |

## 4. Состояния и переходы

**Материал:** `draft → published → archived`; из `archived` можно вернуть в `draft`.
**Версия курса:** `draft → published → retired`. Одновременно опубликована ровно одна версия.
**Медиа:** `uploading → processing → ready`, ветки `failed` и `quarantined` (антивирус).
**Урок у ученика:** `locked → available → opened → completed`.

## 5. Экраны

### 5.1 Библиотека материалов

Таблица: название, тип (иконка), категория, метки, автор, дата изменения, статус публикации,
использование («у 3 курсах»). Вкладки: Усі / Чернетки / Опубліковані / Архів.
Фильтры: тип, категория, метка, автор, период изменения. Массовые действия: опубликовать,
архивировать, сменить категорию, добавить метку. Записей на странице: 10/25/50/100.

### 5.2 Редактор материала

Две вкладки, как в эталоне:
- **«Вміст»** — блоки: кнопка «+» между блоками, перетаскивание за ручку, дублирование,
  удаление с подтверждением, сворачивание длинных блоков. Автосохранение раз в 10 секунд
  и по потере фокуса, индикатор «Збережено о 14:22».
- **«Опис та налаштування»** — название, краткое описание, категория, метки, авторы,
  язык, обложка (16:9, подсказка про форматы), оценка длительности, видимость, публикация.

Панель редактора текста: жирный, курсив, подчёркивание, зачёркивание, списки нумерованный
и маркированный, ссылка, таблица, медиа, изображение, высота строки, отступы, цвет,
очистка форматирования, аккордеон, исходный код, предпросмотр, полный экран.

Предпросмотр: «Як бачить учень» — открывает урок в режиме чтения в модальном окне,
с переключателем «телефон / десктоп».

### 5.3 Редактор курса

Слева дерево: модули и уроки, drag-and-drop между модулями, кнопки «+ Розділ», «+ Урок».
Справа — параметры выбранного элемента. Для урока: материал (поиск по библиотеке или
создать новый), обязательность, минимальное время, порог видео, условие открытия, дата доступа.

Верхняя панель: название курса, статус, «Попередній перегляд», «Опублікувати», «Дії»
(дублировать, архивировать, экспортировать структуру в json).

### 5.4 Публикация

Модалка с чек-листом проверок — зелёные и красные пункты:
- в курсе есть хотя бы один урок;
- у каждого урока задан материал;
- все медиа в статусе `ready`;
- у курса есть обложка и категория;
- если включён сертификат — выбран шаблон;
- нет ссылок на архивированные материалы.
Поле «Що змінилось» (changelog) обязательно, 5–500 знаков.
Кнопка «Опублікувати» неактивна, пока есть красные пункты.

### 5.5 Плеер урока (ученик)

Шапка: название курса, «Урок 3 з 6», крестик (сохраняет позицию).
Тело: блоки в одну колонку, ширина текста 60–72 знака, изображения на всю ширину колонки.
Низ (липкий): прогресс курса тонкой полосой + кнопка «Далі».
Кнопка неактивна, пока не выполнены условия, с подписью-объяснением: «Ще 20 секунд»,
«Подивись відео до кінця», «Познач усі пункти».

Видео-плеер: свой, на `<video>`; при `allow_seek=false` перемотка вперёд заблокирована
до первого полного просмотра; после просмотра — свободная. Скорость 1x/1.25x/1.5x.
Субтитры, если загружены `[решение]`. При потере сети — сообщение и повтор.

### 5.6 Состояния

Загрузка — скелетон блоков. Пусто (урок без контента) — «Матеріал ще не заповнено».
Нет доступа — «Цей урок відкриється після попереднього». Ошибка медиа — «Відео не завантажилось.
Спробувати ще раз» с кнопкой. Офлайн — баннер и локальная очередь прогресса.

### 6.2 Загрузка медиа

Drag-and-drop или кнопка. Показывается: имя, размер, прогресс, кнопка отмены.
Ошибки: «Файл більший за 500 МБ», «Формат не підтримується», «Не вдалося завантажити —
спробуйте ще раз», «Файл не пройшов перевірку безпеки».
После загрузки видео — статус «Обробляємо відео, це займе до 5 хвилин», урок публиковать нельзя.

## 7. Правила и алгоритмы

1. **Версионирование.** Правка опубликованного курса создаёт черновую версию; опубликованная
   продолжает работать. Публикация переводит старую в `retired` в одной транзакции.
2. **Материалы не версионируются отдельно** `[решение]`: правка материала влияет на все курсы,
   где он используется, начиная со следующей публикации курса. Поэтому редактор показывает
   предупреждение «Цей матеріал використовується у 3 курсах».
3. **Завершение урока** требует одновременно: все `require_all` чек-листы отмечены,
   `seconds_spent ≥ min_seconds`, `video_pct ≥ video_threshold_pct` для каждого видео-блока.
4. **Тики времени.** Клиент шлёт `POST /lessons/:id/tick` каждые 15 секунд, только когда
   вкладка активна. Сервер прибавляет не больше 20 секунд за тик (защита от накрутки)
   и игнорирует тики чаще, чем раз в 10 секунд.
5. **Строгий порядок.** При `strict_order=true` урок доступен, если предыдущий обязательный
   завершён. Необязательные не блокируют.
6. **Медиа-пайплайн.** `upload-url` → прямая загрузка в S3 → `complete` → задача `media.process`:
   антивирус → проверка сигнатуры → изображения в webp (320/768/1600) → видео в h264/aac,
   ≤1080p, ≤2.5 Мбит/с, постер на 1-й секунде → `ready`.
7. **Дедупликация.** При совпадении `checksum` в тенанте новый файл не создаётся,
   переиспользуется существующий.
8. **Удаление медиа** запрещено, если `used_in` не пусто: сначала убрать из контента.
9. **Санитизация HTML** на сервере при сохранении, не при выводе. Всё, что не в allowlist,
   вырезается; ссылки получают `rel="noopener noreferrer"`.
10. **Экспорт/импорт структуры курса** в json — для переноса между тенантами, без медиа `[решение]`.

## 9. Отчёты

**Отчёт по материалам**: материал, тип, сколько человек открыло, среднее время, доля
завершивших, в каких курсах используется.
**Отчёт по курсам**: назначено, начали, завершили, среднее время, средний балл, воронка по урокам
(на каком уроке отваливаются).
**Отчёт по медиа**: объём хранилища по тенанту, топ-20 самых тяжёлых файлов, неиспользуемые файлы.

## 12. Крайние случаи

- Два автора редактируют один материал → оптимистическая блокировка по `version`,
  второму показывается «Матеріал змінили. Оновити?» с diff по блокам `[решение]`.
- Видео загружено, но обработка упала → урок нельзя опубликовать, автору уходит уведомление.
- В уроке 40 блоков и 15 изображений → страница грузится лениво, изображения — `loading=lazy`.
- Ученик открыл урок, свернул вкладку на час → тики не идут, время не накручивается.
- Материал архивирован, а курс с ним опубликован → публикация блокируется проверкой.
- SVG с внешней ссылкой → ссылка вырезается санитайзером, файл принимается.

## 13. Критерии приёмки

1. **Дано** курс из 4 уроков, **коли** методист меняет второй урок и публикует,
   **тоді** ученик с активной записью продолжает видеть старую версию, новый — новую.
2. **Дано** урок с `min_seconds=60`, **коли** ученик пробует нажать «Далі» через 20 секунд,
   **тоді** кнопка неактивна с подписью «Ще 40 секунд».
3. **Дано** видео с `video_threshold_pct=90`, **коли** просмотрено 85%, **тоді** урок
   не завершается; при 91% — завершается.
4. **Дано** загрузка файла 600 МБ, **тоді** отказ до начала передачи с понятным текстом.
5. **Дано** HTML с `<script>` в блоке текста, **коли** сохранили, **тоді** в базе скрипта нет.
6. **Дано** одинаковый файл загружен дважды, **тоді** в S3 один объект, в базе одна запись.
