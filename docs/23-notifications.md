# Lola LMS — ТЗ. Часть 23. Сповіщення: канали, шаблони, правила доставки

## 1. Назначение и границы

Уведомления — единственный способ довести обучение до человека, который не открывает
систему сам. Главный канал — Telegram, резервный — SMS, для руководителей — почта.
Модуль отвечает за шаблоны, маршрутизацию, тихие часы, дедупликацию и журнал.

Входит: каналы, шаблоны и переменные, настройки тенанта и человека, очередь и доставка,
Telegram-бот, дайджесты, журнал.
Не входит: конкретные события модулей (перечислены в их документах).

## 3. Сущности и поля

### 3.1 `notification_templates`

| Поле | Тип | Обяз. | Комментарий |
| --- | --- | :-: | --- |
| `code` | text | ✓ | `enrollment_due_soon` и т. д. |
| `channel` | text | ✓ | `telegram` \| `sms` \| `email` \| `push` \| `inapp` |
| `locale` | text | ✓ | `uk` \| `en` |
| `subject` | text | — | для почты |
| `body` | text | ✓ | шаблон с `{{переменными}}`, ≤2000 |
| `buttons` | jsonb | — | для Telegram: `[{text, action}]` |
| `is_enabled` | boolean | ✓ | |
| `is_mandatory` | boolean | ✓ | нельзя отключить человеку (дедлайны, аттестации) |
| `throttle` | jsonb | — | `{max_per_day: 1, per_subject: true}` |
| `version` | int | ✓ | правка создаёт версию, старые отправки ссылаются на свою |

### 3.2 `notifications` — очередь и журнал

`user_id`, `code`, `channel`, `locale`, `payload jsonb` (значения переменных),
`rendered_body` (что реально отправили), `status` (`queued` \| `sending` \| `sent` \|
`failed` \| `skipped` \| `read`), `skip_reason` (`quiet_hours` \| `unsubscribed` \|
`duplicate` \| `no_channel` \| `blocked`), `error`, `attempt`, `scheduled_for`,
`sent_at`, `read_at`, `ref_type`, `ref_id`, `dedupe_key`.

### 3.3 Настройки

**Тенант** (`tenant.settings.notifications`): тихие часы (по умолчанию 09:00–20:00 по
таймзоне точки), каналы по умолчанию, отправитель SMS, адрес почты, дайджест руководителю
(день и час), лимит SMS в месяц, эскалация (через сколько уведомлять руководителя).

**Человек** (`user_notification_prefs`): по каждому коду — включено/выключено и канал;
обязательные коды показываются, но переключатель заблокирован с подписью
«Це сповіщення не можна вимкнути».

### 3.4 Переменные шаблонов

Общие: `{{user.first_name}}`, `{{user.full_name}}`, `{{location.name}}`,
`{{position.name}}`, `{{tenant.name}}`, `{{link}}` (автологин-ссылка).
Обучение: `{{course.title}}`, `{{due.date}}`, `{{due.days_left}}`, `{{progress.pct}}`,
`{{score}}`, `{{attempts_left}}`, `{{mentor.name}}`, `{{certificate.number}}`.
В редакторе — список доступных переменных с подстановкой по клику и предпросмотром
на реальных данных.

## 4. Каналы

| Канал | Когда используется | Ограничения |
| --- | --- | --- |
| Telegram | основной для всех | лимит 25 сообщений/сек на бота, 1/сек на чат; блокировка бота → 403 |
| SMS | OTP и критичное при недоступном Telegram | стоимость, лимит тенанта, 70 знаков в сегменте |
| E-mail | руководителям, дайджесты, выгрузки | требует адрес |
| Push (PWA) | R2, дублирует Telegram | требует разрешения браузера |
| In-app | колокольчик в интерфейсе | всегда, без ограничений |

**Правило выбора канала:** Telegram (если привязан и не заблокирован) → SMS (если код
критичный и включён) → in-app. Почта только для кодов, помеченных `email`.

## 5. Экраны

### 5.1 Мої сповіщення (человек)

Список кодов, сгруппированных по темам (навчання, атестації, нагадування, хаб),
переключатели; обязательные — с замком. Внизу: «Канал за замовчуванням» и кнопка
«Перевірити» — отправляет тестовое сообщение.

### 5.2 Шаблони (админ)

Таблица: код, канал, язык, включён, последнее изменение. Редактор: поле текста,
список переменных, предпросмотр на выбранном человеке, кнопка «Надіслати собі»,
история версий, кнопка «Повернути стандартний текст».

### 5.3 Журнал уведомлений

Таблица: время, человек, код, канал, статус, причина пропуска, текст (по клику),
ошибка. Фильтры: период, человек, код, канал, статус, точка. Кнопка «Надіслати повторно».

### 5.4 Ручная рассылка (руководитель)

Аудитория (конструктор из `15`), текст (до 500 знаков), канал, подтверждение с числом
получателей и предупреждением о тихих часах. Рассылка попадает в журнал как код `manual`.

### 5.5 Колокольчик в интерфейсе

Список последних 50, непрочитанные выделены, клик ведёт к предмету уведомления,
кнопка «Позначити все прочитаним».

## 6. Правила и алгоритмы

1. **Постановка в очередь.** Модуль не отправляет сам: пишет строку в `notifications`
   с `dedupe_key`. Отправкой занимается задача `notification.dispatch`.
2. **Дедупликация.** `dedupe_key = code + user_id + ref_id + дата`; повторная постановка
   с тем же ключом даёт `skipped: duplicate`.
3. **Тихие часы.** Если `scheduled_for` попадает в тихие часы точки человека, отправка
   переносится на ближайшее начало рабочего окна. Исключение: OTP и коды с
   `ignore_quiet_hours=true` (аварийные).
4. **Троттлинг.** Не больше `throttle.max_per_day` сообщений одного кода одному человеку;
   и не больше 10 любых уведомлений в сутки на человека без явного указания
   `bypass_daily_limit` `[решение]`.
5. **Ретраи.** При временной ошибке (сеть, 5xx, лимит) — 5 попыток с экспонентой
   (1, 5, 25, 60, 180 минут). При 403 от Telegram (бот заблокирован) —
   `telegram_blocked=true`, канал переключается на SMS, руководителю уведомление.
6. **Эскалация.** Если по коду с `escalate_after_hours` человек не отреагировал
   (не открыл ссылку), уведомление уходит руководителю точки.
7. **Автологин-ссылка** `{{link}}`: одноразовый токен на 10 минут, привязан к `chat_id`
   и коду уведомления; после использования аннулируется.
8. **Дайджест руководителю** собирает за период: сколько просрочено, кто не начал,
   что ждёт проверки, аттестации на неделю — одним сообщением вместо десяти.
9. **Язык** берётся из `users.locale`, иначе из тенанта; при отсутствии шаблона на языке —
   fallback на `uk` с пометкой в журнале.
10. **Шаблон изменён** — отправленные ранее уведомления сохраняют свой текст
    (`rendered_body`), журнал не переписывается.

## 7. Telegram-бот

- Привязка: человек открывает `/start <token>` по ссылке из интерфейса; токен одноразовый,
  живёт 15 минут, привязывает `chat_id`.
- Команды: `/start`, `/menu` (мої завдання), `/help`, `/stop` (отписка от необязательных).
- Кнопки под уведомлениями: «Пройти» (автологин-ссылка), «Відкласти на день»
  (переносит напоминание, максимум дважды), «Не нагадувати про це» (только для необязательных).
- Бот не ведёт обучение в чате: всё открывается в вебе.
- Ошибки: 403 — блокировка, 429 — троттлинг с `retry_after`, 400 «chat not found» —
  сброс привязки.

## 8. Отчёты

**Доставляемость**: по кодам и каналам — отправлено, доставлено, ошибок, пропущено
и почему.
**Реакция**: доля открывших ссылку, среднее время до реакции по кодам — показывает,
какие формулировки работают.
**SMS-расходы**: сегментов, стоимость, по точкам.
**Заблокированные боты**: список людей, у которых Telegram недоступен — им нужен другой канал.

## 10. Фоновые задачи

`notification.dispatch` (каждую минуту, партиями с учётом лимитов каналов),
`notification.retry`, `notification.escalate` (ежечасно), `digest.build` (по расписанию),
`notification.cleanup` (удаление тел старше срока хранения), `telegram.health`
(проверка бота раз в час).

## 11. Крайние случаи

- Человек сменил номер → привязка Telegram сохраняется (она по `chat_id`), SMS идут на новый.
- Тенант исчерпал лимит SMS → критичные уведомления идут в Telegram и in-app,
  администратору алерт «Ліміт SMS вичерпано».
- Массовое назначение 3000 людям в 20:05 → всё уходит в очередь и отправляется утром
  с 09:00, растянуто по лимиту 25/сек.
- Человек нажал «Відкласти» три раза → третья кнопка не показывается, напоминание приходит.
- Шаблон содержит переменную, которой нет в payload → подстановка пустой строкой,
  предупреждение в журнале, отправка не блокируется.
- Бот удалён и создан заново → все `chat_id` недействительны, нужна массовая перепривязка;
  предусмотреть кнопку «Надіслати всім посилання на привʼязку».

## 12. Критерии приёмки

1. **Дано** тихие часы 09:00–20:00, событие в 21:30, **тоді** уведомление уходит
   в 09:00 следующего дня, в журнале причина «quiet_hours».
2. **Дано** два одинаковых события подряд, **тоді** второе `skipped: duplicate`.
3. **Дано** человек заблокировал бота, **тоді** первая же отправка ставит `telegram_blocked`,
   следующее критичное уходит SMS, руководителю уведомление.
4. **Дано** нажата кнопка «Пройти» в Telegram, **тоді** открывается урок сразу,
   без ввода кода; повторное нажатие той же ссылки через 15 минут требует входа.
5. **Дано** шаблон отредактирован, **тоді** ранее отправленные уведомления в журнале
   показывают старый текст.
6. **Дано** ручная рассылка на 200 человек, **тоді** она видна в журнале как `manual`
   с автором и текстом.
