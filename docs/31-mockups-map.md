# Lola LMS — мокапы экранов (19.09.2026) и карта соответствия

Пакет `lola-mockups` (90 экранов: 18 на телефоне для линейного персонала, 72 на десктопе
для администратора, включая панель оператора) лежит в `docs/mockups/` — `index.html`
(обзор по разделам) и `screens/<Имя>.html` (по экрану). Мокапы сделаны по утверждённому
бренд-буку и являются **визуальной спецификацией**: каждый экран Lola собирается по своему
мокапу. Где мокап расходится с текстом ТЗ, побеждает мокап (он новее); расхождение и
решение фиксируются в `28`. Данные в мокапах (имена, точки, цифры) — примеры, они не
переносятся; тексты интерфейса берутся из мокапов дословно в `i18n/locales/uk.json`.

## Общие элементы

- **Админка (1440)**: левая колонка 236px — четыре брендовых квадрата вместо логотипа;
  пять разделов `Навчання · Контент · Люди · Звіти · Налаштування`, у активного раздела
  подпункты (`Main`: Завдання · Траєкторії · Черга перевірки · Каталог); внизу карточка
  человека с инициалами и активной ролью (`01` §1.9.2). Шапка страницы: хлебные крошки,
  заголовок 900, справа одно солнечное действие и при необходимости «Відхилити зміни».
  Фильтры и вкладки — чипы со счётчиками, активный чип чернильный. Списки — таблицы
  с колонками ЗАГЛАВНЫМИ, строки-карточки. Правая колонка 300px для сводок и параметров.
- **Кабинет (390×844)**: без шапки, заголовок 28px/900, нижняя панель `Навчання · Каталог ·
  Бонуси · Профіль`, липкая солнечная кнопка внизу у сценариев прохождения, стрелка «←»
  и прогресс «3 з 5» у урока/теста.
- **Цвета состояний**: солнце — действие и «В ПРОЦЕСІ»; бирюза — результат и «ВИКОНАНО»;
  коралл — «ПРОВАЛЕНО», «Протерміновано», «Критично»; приглушённый — «НЕ РОЗПОЧАТО».
- **Подсказки-обоснования** (жёлтые/красные плашки в мокапах: «Ці правила діють тільки для
  цього призначення», «Файл застосовується цілком або ніяк», «Баланс — не збережене поле…»)
  переносятся в интерфейс как есть — это тексты для пользователя, а не комментарии дизайнера.

Обозначения: ✅ соответствует · 🟡 частично · ❌ не сделан или не по мокапу · PR — очередь `30` §4;
`shell` — PR `ui-shell` (каркас), R3 — не в R1.
