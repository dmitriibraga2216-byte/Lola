## Как применили ответ (22.09.2026)

- **Q-01: а.** Прод остаётся на `devbox` (Proxmox VM через Tailscale, 2 vCPU / 4 ГБ) — это и
  есть отдельная от стенда машина, роль постоянного прод-сервера за ней закреплена. Отдельная
  VM 4 vCPU / 8 ГБ по `26` — когда понадобится по нагрузке, отдельной задачей. D-070 закрыт.
- **Q-02: а.** Постоянный адрес уже есть — `app.lmscappi.pp.ua`, вместо временной ссылки
  `trycloudflare.com`. D-071 закрыт.
- **Q-03: а.** Формат файла для «Імпортувати» пока не пришёл — на этой итерации кнопки
  «Імпортувати» на `/admin/courses` и `/admin/resources` убраны совсем (не заглушка), вместе с
  неиспользуемыми ключами i18n (`course.import`/`importHint`, `resource.import`/`importHint`).
  Импорт вернётся отдельной задачей, когда придёт пример файла.
- **Q-04: а.** Подтверждено как есть — код не менялся.
- **Q-05: а.** При аудите выяснилось, что статус «Відмовлено» и вкладка фильтра на
  `/admin/attempt-requests` уже реализованы (enum `attempt_request_status`, вкладка, i18n) ещё
  в #36 — [33](docs/33-debts-2026-09-20.md) D-012 ошибочно числился нерешённым. Кода менять не
  потребовалось.
- **Q-06: а.** Буквально — «завести справочник», но отдельного перечисления значений «Спосіб
  призначення» в этом PR не заводим: значение продолжает выводиться автоматически из
  `enrollments.source`+`assignments.kind`, чтобы не придумывать перечисление молча (CLAUDE.md
  п. 13). Если понадобится справочник — отдельная задача с обсуждением списка значений.
- **Q-07: а.** Буквально — «переделать под мокап», но замовником по факту принята текущая
  реализация (QR на экране тренера — безопаснее, участник не подделает свою явку). Код не
  менялся; [31](docs/31-mockups-map.md) строка `Meetup` уточнена — расхождение с мокапом
  принято заказчиком, а не является дефектом.
- **Q-08: а.** Подтверждено как есть — код не менялся.
- **Q-09: а.** Буквально — «связать автоматически», но по факту решение — оставить объявление
  «Подія» и запись на событие хаба двумя независимыми действиями (разные жизненные циклы). Код
  не менялся.
- **Q-10: а.** Буквально — «сделать в этой версии», но по факту двухфакторный вход
  (`adminTwoFactor`) переносится на следующую версию: нужен новый экран входа и промежуточная
  сессия — отдельная задача. Переключатель в настройках остаётся неактивным, код не менялся.
