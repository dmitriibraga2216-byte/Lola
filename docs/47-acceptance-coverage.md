## Как читать

Каждый критерий сопоставлен с тестом по тексту «дано / коли / тоді»: тест засчитывается, только если
он **проверяет результат**, а не упоминает его. Статусы:

| Статус | Значит |
| --- | --- |
| **покрыт** | есть тест, который проверяет критерий целиком (числа в тесте могут отличаться, логика — та же) |
| **не покрыт** | теста нет или он проверяет часть критерия (пометка «частично: …»); код при этом критерий выполняет |
| **не выполняется** | код критерий не выполняет или противоречит ему (ссылка на место) |
| **вопрос** | ТЗ неоднозначно, противоречит другому документу или критерий вне кода (инфраструктура, Cloudflare) |

Колонка «PR» — каким PR серии `acceptance-sweep-N` строка закрыта; решения по «вопросам» — `docs/v2/44` §22.
Статусы обновляются в этом файле тем же PR, что закрывает строку.
