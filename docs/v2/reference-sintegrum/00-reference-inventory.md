## Не закрытые разделы (после второго прохода, «хоть 60 / СДЕЛАЙ АБСОЛЮТНО ВСЕ»)
Второй проход закрыл почти все ⛔-пункты первой версии. Честно остаются открытыми (принципиально не проверяемо без нарушения read-only, либо не хватило времени в рамках бюджета):
- **Карточка кандидата (детальный экран)** — невозможно снять: на эталоне 0 кандидатов, открыть карточку можно только создав кандидата, что запрещено правилом read-only. Остаётся `[гипотеза]` без возможности закрытия на этом эталоне.
- **«Конструктор сертифікатів»** (упоминается в `/company-settings`, п.8 в CLAUDE.md) — сам конструктор (модальное окно/отдельный экран) не открывался повторно на этом проходе.
- **Детальный экран проверки одного ответа** в `/review/*` (Г-06.2) — не снят, во всех 7 категориях очередь пуста, строк для клика нет.
- **Формы редактирования** `/branches`, `/jobs`, `/departments` (клик по строке даёт только тултип, не форму) — Г-10.5.
- **Условия/ветвления на связях (стрелках) графа треку** — попытка right-click по стрелке между узлами не изолировала клик от уже выделенного узла; не проверено технически.
- **Стор. 2 списку `/jobs`** (после ~20 посад на стор.1) — не открывалась.
- **Полный список Schemas в Swagger `/api-doc`** — прокручен частично, не до конца списка.
- **Состав select «Тип завдання»** в фильтрах `/review/*` (Г-06.3) — не раскрывался.
- **Механизм/UI делегування** («Делеговані мною» таб в `/review/*`, Г-06.5) — кнопка делегирования не найдена на пустом экране.
- Детальная разбивка прав по ролям (какая роль что именно видит/может) — снят только список ролей, не матрица прав.

## Общий принцип найденных дополнений к Lola
Модули, отсутствующие в исходном ТЗ Lola и подлежащие добавлению:
1. **Рекрутинг целиком**: Кандидати (канбан+список), Вакансії (+ AI-генерация описаний, + інтеграції з job-бордами work.ua/robota.ua/telegram на рівні компанії/особисто/рекрутера), трек-категорія «Рекрутинг» з AI-інтерв'юером і «3Д-резюме».
2. **Офбординг** как отдельная трек-категория (симметрично онбордингу).
3. **Опитувальники** — отдельный конструктор анкет (не путать с психологічними тестами).
4. **Розширена статистика**: по менторам, рекрутерам, філіям, відділам — отдельные экраны, не только общий дашборд.
5. **Тарифна модель** с раздельными лимитами «співробітники / кандидати / сховище» и безлімітними треками.
6. **Ролі як розширюваний довідник** (не enum) с системными и потенциально кастомными ролями.
7. **Звіт про помилки** — фидбэк-канал от прохожего трека к автору контента.
8. **Бібліотека модулів** — явный переиспользуемый контент отдельно от треков.
9. **Настройки компанії**: мультиязычность интерфейса (32 языка), API-токен, сертифікати, авто-архівація відхилених кандидатів, авто-відправка 3Д-резюме за умовою оцінки, 2FA, норми відпустки/лікарняного за замовчуванням з можливістю перевизначення на рівні філії.
10. **Оргструктура як окрема сутність** (`/org-structure`) — дерево-конструктор з двома типами вузлів (посада-заглушка / конкретний співробітник), окремий від довідника посад (`/jobs`) і від довідника відділів (`/departments`).
11. **Довідник посад** (`/jobs`) з можливим зв'язком «посада → треки за замовчуванням» (колонка «Треки» в таблиці).
12. **Сховище (Storage) як окремий білінгований ресурс** (`/storage`) з розбивкою використання за категоріями треків і посторінковим списком файлів, а не просто «загальний ліміт».
13. **Публічний API** (`/api-doc`, Swagger/OpenAPI, `api.sintegrum.com`) — Lola в оригінальному ТЗ такого не мала; внутрішні назви сутностей API (`Course`, `Student`, `CvProgressItem`) розходяться з UI-мітками (Трек, учасник треку, 3Д-резюме) — важливо для агента-реалізатора не плутати ці словники.
