# Статистика — снято с эталона (Sintegrum, brghotels.sintegrum.com)

## 1. Назначение
Раздел агрегированной аналитики: дашборд компании + срезы по менторам, рекрутерам, філіям, відділам.

## 5. Экраны

### 1.1 Дашборд — `/dashboard`
Фильтры сверху: **Філії** (select), **Відділ** (select).
Виджеты (каждый с переключателем периода **Тиждень / Місяць / 6 Місяців** и линейным графиком):
- «Кількість зареєстрованих співробітників» — число + график
- «Пройдених модулів» — число «сьогодні» + график
Ниже — по одной секции на каждую категорию треков (загорложена именем категории — «Рекрутинг», «Інтеграція», «Підвищення кваліфікації», далее остальные категории треков по аналогии), и в каждой секции — по 4 карточки-метрики (двухколоночная сетка, у каждой свой переключатель периода и график):
- Рекрутинг: «Кількість нових 3Д-резюме», «Всього ...», «Опрацьовано 3-д резюме», «Час в р...» (час в роботі).
- Інтеграція: «Проходять інтеграцію», «Кількіс...».
- Підвищення кваліфікації: «Проходять підвищення кваліфікації», «Кількіс...».
Последняя секция — «Менторинг» (не привязана к конкретному треку): «Перевірено завдань», «Непере... завдань» (неперевірено).
[гипотеза] Названия и состав карточек для секций Онбординг/Атестація/Психологічні тести/Офбординг не сняты дословно (пролистаны быстро) — по аналогии должны повторять паттерн «Проходять <категорію>» + «Кількість <щось> сьогодні». Чем проверяется: медленно прокрутить `/dashboard` целиком и выписать все заголовки карточек.
Баннер лимита тарифа вверху: «Увага! Незабаром буде досягнуто ліміту за кількістю співробітників. Залишилось реєстрацій: N» + кнопка «Змінити тариф» + закрыть (X).

### 1.2 Статистика менторів — `/mentors?checked_at=YYYY-MM-DD_YYYY-MM-DD`
Заголовок: «Ментори».
Фильтры: **Пошук** (текст), **Філії** (select), **Вибрати період** (date range picker, формат MM/DD/YYYY – MM/DD/YYYY).
Кнопка **Експорт** (иконка выгрузки).
Таблица, колонки (слева→направо): Ментор (ссылка на профиль), Філії, Завдань перевірено, У середньому за день, Прийнято, Відхилено, Загальний час перевірки, Ост. перевірка (дата+время, формат DD.MM.YYYY, HH:MM).

### 1.3 Статистика рекрутерів — `/recruiters?created_at=YYYY-MM-DD_YYYY-MM-DD`
Заголовок «Рекрутери». Фильтры: Пошук, Філії, Вибрати період. Кнопка Експорт.
Таблица, колонки: Рекрутер, Не почали, Проходять, 👎 (відхилено), 🕐 (в очікуванні), Найняті, Архівні.
Данные по воронке кандидатов в разрезе рекрутера, повторяет статусную модель кандидатів (см. 03-candidates.md).

### 1.4 Статистика по філіям — `/statistic-branches`
Заголовок «Статистика по філіям». Фильтр: Пошук. Кнопка Експорт.
Таблица, колонки: Місто (название филиала/отеля), Проходять, Зареєстровано.
Список филиалов реального клиента (для справки, не переносить в ПРОДУКТ буквально): Готель "Морський" (Одеса), "Волна" (Одеса), "Порто-Франко" (Одеса), "Дерибас" (Одеса), "Solva" (Поляна), "Ніколь" (Буковель), "Марина" (Буковель), "Emerald House" (Микуличин), "Вілла Ладна" (Татарів), "Qzone" (Санжейка), "Новий" (Буковель), Керуюча компанія, Готель "Консул". [решение] Ставки, что «Керуюча компанія» — служебный «нулевой» филиал верхнего уровня (holding) — сущность `branch(is_headquarters: bool)`.

### 1.5 Статистика по відділам — `/statistic-departments`
Заголовок «Статистика по відділам». Фильтры: Пошук, **Статус** (select). Таблица, колонки: Відділ, Проходять (+ вероятно ещё справа, не досмотрено — [гипотеза]).
Реальный список отделов отельной сети (словарь предметной области): Відділ навчання, Хаускіпінг, Служба прийому та розміщення, Майстри, Ресторан, Відділ продажів, Call-центр, Фінансовий відділ, Відділ розвитку, Керуючі, Операційний, Лікувальний центр.

## 15. Гипотезы
- Г-01.1 — состав виджетов дашборда ниже первого экрана не снят полностью.
- Г-01.2 — `/recruiters` не снят.
- Г-01.3 — `/statistic-branches` не снят.
- Г-01.4 — `/statistic-departments` не снят.
