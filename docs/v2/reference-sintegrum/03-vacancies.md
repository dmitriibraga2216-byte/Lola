# Вакансії — снято с эталона (Sintegrum)

## 1. Назначение
Модуль публикации вакансий и генерации ссылки на авто-собеседование по треку. Модуль отсутствует в исходном ТЗ Lola.

## 5. Экраны

### 3.0 Верхний уровень модуля
Три вкладки: **Вакансії** (список) · **Шаблони** (не раскрыта содержательно — см. гипотезы) · **Інтеграції**.

### 3.1 Список вакансій — `/vacancies`
Пустое состояние: иконка, текст «Немає відкритих вакансій», кнопка «+ Створити вакансію» → дропдаун из 2 пунктов: **«Нова вакансія»** / **«Обрати шаблон»**.
[гипотеза] Колонки таблицы при наличии вакансий не сняты (нет данных). Чем проверяется: создать тестовую вакансію, посмотреть список.

### 3.2 Створення вакансії (форма, полноэкранная, не модалка)
Поля сверху вниз:
- Бейдж статуса «Вакансія» (зелёный) — [гипотеза] отображает состояние (чернетка/опубліковано).
- **Рекрутер** (select, «Обрати рекрутера»).
- **Назва вакансії** (текст).
- Ряд из 4 select: **Категорія**, **Рекрутинговий трек**, **Філія**, **Відділ**.
- **Опис вакансії** — rich-text редактор (B/I/списки/очистка формата) + кнопка **«Створити з AI»** (генерация текста ИИ).
- **Вимоги** — аналогичный rich-text блок + «Створити з AI».
- **Обов'язки** — аналогичный rich-text блок + «Створити з AI».
- **Додаткова інформація** — аналогичный rich-text блок (без AI-кнопки не проверено, скорее всего есть).
- Подсказка (красным текстом, важная бизнес-логика): **«Оберіть трек та філію для створення посилання на автоматичну співбесіду»** — т.е. вакансия должна быть привязана к треку (типа «Рекрутинг») + філії, чтобы система сгенерировала ссылку кандидату на авто-собеседование.
- **Умови роботи**: 4 select — Тип зайнятості, Формат, Країна, Місто.
- **Досвід роботи** (select), **Освіта** (select) — в одну строку.
- **Зарплата**: поля «від» / «до» + select валюти (дефолт UAH) + чекбокс **«Показувати кандидатам»** (скрытие вилки ЗП от публикации).
- **Іноземні мови** — кнопка «+ Додати мову» (динамический список язык+рівень, не раскрыт детально).
- **Параметри публікації** — блок «Немає підключених інтеграцій» (тянет состояние из вкладки «Інтеграції», см. 3.4).
- Кнопка внизу: **«Зберегти шаблон»**. [гипотеза] Основная кнопка публикации/сохранения вакансии (например «Опублікувати»/«Створити») не найдена на первом проходе — возможно появляется в другом месте формы (sticky-header) или после заполнения обязательных полей. Чем проверяется: заполнить обязательные поля и повторно осмотреть форму сверху и по бокам.

### 3.3 Шаблони вакансій — вкладка «Шаблони»
Раскрыта при повторном проходе (первая попытка промахнулась мимо вкладки по координатам). Пустое состояние: «Немає готових шаблонів» + кнопка **«Створити шаблон»**. Подтверждает связь с пунктом «Обрати шаблон» на экране 3.1 (создание вакансии из готового шаблона) и с кнопкой «Зберегти шаблон» на экране 3.2. [решение] Шаблон вакансії — самостоятельная переиспользуемая сущность (`vacancy_template`), которую можно как создать «с нуля» на этом экране, так и получить из формы редактирования конкретной вакансии («Зберегти шаблон»).

### 3.4 Інтеграції — вкладка «Інтеграції» (важная находка)
Список карточек-интеграций для публикации вакансий, **сгруппированный по владельцу**:
- Группа **«BRG Hotels»** (компания целиком, общий аккаунт) — карточки **work.ua**, **robota.ua**, **telegram**, у каждой — ссылка на сервис и кнопка «Підключити».
- Далее — группа **«Персональний»** (аккаунт текущего пользователя) с теми же 3 карточками.
- Далее — по группе **на каждого рекрутера отдельно** (сняты примеры: по одному аккаунту на рекрутера, список прокручивается дальше — ФИО не переносятся) — с теми же 3 карточками work.ua/robota.ua/telegram.
[решение] Модель: `job_board_integration(owner_type: company|personal|recruiter, owner_id, provider: work_ua|robota_ua|telegram, connected: bool)` — публикация вакансии может идти от имени компании или от личного кабинета конкретного рекрутера на внешней площадке.
Есть строка поиска «Пошук» вверху вкладки (поиск по рекрутеру, видимо).

## 15. Гипотезы
- Г-03.1 — колонки списка вакансий при наличии данных не сняты.
- Г-03.2 — назначение бейджа-статуса «Вакансія» на форме создания.
- Г-03.3 — где кнопка публикации/сохранения вакансии (кроме «Зберегти шаблон»).
- Г-03.4 — содержимое вкладки «Шаблони» не раскрыто.
- Г-03.5 — состав полей «Іноземні мови» (язык + рівень?) не раскрыт подробно.
