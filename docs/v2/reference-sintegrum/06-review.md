# Завдання на перевірку — снято с эталона (Sintegrum)

## 1. Назначение
Инбокс ментора/рецензента: список ответов пользователей на «ручные» (не авто-проверяемые ИИ/системой) задания, требующих проверки человеком. Один экран на категорию трека (7 категорий — без «База знань», «Бібліотека модулів», «Звіт про помилки», т.к. там нечего перевіряти).

## 5. Экраны
Единый шаблон подтверждён для **всех 7 URL** без исключения (`/review/recruiting`, `/review/onboarding`, `/review/integration`, `/review/training`, `/review/attestation`, `/review/psychological`, `/review/offboarding`) — каждый открыт и сверен по отдельности:

Заголовок = назва категорії. Фильтры: **Філії** (select), **Трек** (select), **Вибрати період** (date range, поле «–»), **Тип завдання** (select).
Два таба над таблицей: **«Завершені»** / **«Делеговані мною»** — [решение] второй таб означает, что ментор может делегировать проверку конкретного задания другому ментору/пользователю, и есть отдельный список того, что делегировано именно текущим пользователем.

**Полный состав колонок таблицы** (сняты дословно на всех 7 экранах, порядок слева направо):
**Прізвище, Ім'я · Філії · Трек · Тип завдання · Назва завдання · Кількість спроб · Розрахунковий час · Час на контент · Час на випробування · Дата виконання**.
(На `/review/attestation` колонка «Розрахунковий час» не зафиксирована в тексте страницы — [гипотеза] либо скрыта при пустых данных, либо у категории «Атестація» на неё не выводится, не до конца ясно — расхождение минорное, состав остальных 9 колонок идентичен на всех 7 экранах.)

[решение] Модель одной строки очереди на проверку: `review_item(employee, branch, track, task_type, task_name, attempts_count, estimated_time, content_time, attempt_time, completed_at, delegated_to?)`. Разделение «Час на контент» vs «Час на випробування» — [решение] время, потраченное на изучение материала, отдельно от времени, потраченного на выполнение/сдачу испытания — та же пара метрик, что «Плановий час» vs «Час проходження» в карточке сотрудника (04-employees.md).

На всех 7 URL на момент аудита очередь пуста («немає даних»), несмотря на 43 реальных сотрудников — [гипотеза сохраняется]: означает, что все пройденные на данный момент задания были авто-проверяемыми (тесты) либо очередь уже разобрана. Чем проверяется: найти сотрудника с непроверенным вручную заданием (текстовым/відео) и открыть соответствующий `/review/<category>`.

## 15. Гипотезы

- Г-06.3 — состав select «Тип завдання» — не раскрыт (список опций не открывался).
- Г-06.4 *(закрыта)* — идентичность шаблона подтверждена по всем 7 категориям индивидуально.
- Г-06.5 — точный механизм и UI делегирования («Делеговані мною») — кнопка/действие делегирования не найдена на пустом экране, только сам таб-фильтр.
- Г-06.6 — отсутствие колонки «Розрахунковий час» именно на `/review/attestation` — перепроверить, баг это эталона или осознанное отличие.
