# Опитувальники — снято с эталона (Sintegrum)

## 1. Назначение
Конструктор произвольных (не тестовых, не оцениваемых) опросов — обратная связь, замер адаптации и т.п. Отдельный от «Психологічні тести» модуль: там — валидированные психометрические методики с интерпретацией баллов, здесь — обычные анкеты.

## 5. Экраны

### 7.1 Список опитувальників — `/questionaries`
Заголовок «Опитувальники», Пошук. Таблица: **Дата створення** · **Назва** (+ вероятно доп. колонки правее, не досмотрено).
В эталоне 1 живая анкета: «Опитування адаптації нового співробітника» (14.07.2026).

### 7.2 Редактор опитувальника (клик по строке)
Заголовок «Опитувальник», кнопка **«Зберегти»**.
Поля: **Назва**, **Опис** (текстовое, поддерживает эмодзи — реальный пример описания снят дословно: «Ми хочемо дізнатися, як проходить ваш період адаптації після завершення стажування...»), переключатель **«Анонімне опитування»**.
Далее — список вопросов, у каждого: **«Назва питання»** (текст вопроса) + селектор типа + «Обов'язково» (toggle).

**Типы вопросов (сняты дословно, 3 шт.):**
1. **«З варіантами відповіді»** — список вариантов (нумерованный, 1..N) + кнопка «Додати варіант». [гипотеза] не уточнено, single- или multi-select — по умолчанию похоже на single (радио), но не проверено явно.
2. **«Лінійна шкала»** — числовой диапазон, границы настраиваемые (в примерах все — от 1 до 10, поля «1» и «10» редактируемые).
3. **«З довгою відповіддю»** — открытый текстовый ответ + поле **«Підказка для відповіді»** (placeholder-хинт).

Внизу — кнопка **«Додати питання»** (добавить новый вопрос).
Реальный пример анкеты (7 вопросов): 2× «З варіантами відповіді», 3× «Лінійна шкала», 1× «З варіантами відповіді» (4 варианта), 1× «З довгою відповіддю» — все помечены «Обов'язково».

## 15. Гипотезы
- Г-07.1 — колонки таблицы списка опитувальників правее «Назва» не досмотрены.
- Г-07.2 — тип «З варіантами відповіді»: одиночный или множественный выбор — не подтверждено.
- Г-07.3 — куда и кому назначается опитувальник (трек? рассылка? отдельная категория треков «Опитувальник» видна была в карточке сотрудника — см. 04-employees.md — значит опрос тоже назначается как элемент трека сотруднику) — связь между `/questionaries` (конструктор) и категорией трека «Опитувальник» в профиле сотрудника не проверена явно кликом.
- Г-07.4 — как выглядят результаты/аналитика по опросу (агрегация ответов) — экран не найден/не проверен.
