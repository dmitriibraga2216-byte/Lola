# docs/v2/reference-sintegrum — исходный аудит второго эталона

Журнал аудита установки Sintegrum (`brghotels.sintegrum.com`), проведённого 20.09.2026.
Это **источник требований, а не ТЗ**: из него вырос пакет `docs/v2`, и на него ссылаются
строки «Чем проверяется» в гипотезах пакета.

## Зачем это в репозитории

В `docs/v2` около семидесяти мест помечены `[гипотеза]` — то, что на эталоне снять не
удалось, с принятым решением и инструкцией, как проверить. Инструкции ссылаются на конкретные
экраны и URL этого эталона. Без журнала аудита проверить гипотезу нельзя: URL-карта, состав
снятых экранов и список незакрытых разделов есть только здесь.

Начинать с `00-reference-inventory.md` — полная URL-карта, что снято, что осталось
непроверенным, и сводный список найденных дополнений.

## Как этим пользоваться

1. Гипотеза в документе пакета говорит «Чем проверяется: открыть такой-то экран».
2. Здесь находится, что на этом экране уже было снято и с какой полнотой.
3. Если снятого хватает — гипотеза закрывается правкой документа пакета **с
   пометкой-исправлением**, а не тихой заменой.
4. Если нет — нужен повторный проход по эталону.

## Ограничения, которые соблюдались при снятии

- Эталон только на чтение: ничего не создавалось, не изменялось, не удалялось, формы не
  отправлялись. Отсюда часть пробелов: экраны, которые открываются только после создания
  записи (карточка кандидата, конструктор сертификатов, детальная проверка ответа), снять
  было нельзя.
- Копировались требования и логика, не код, не вёрстка, не наполнение.
- Персональные данные людей из эталона удалены при переносе в репозиторий.

## Чего здесь нет и не будет

- Кода и вёрстки эталона.
- Реальных данных клиента эталона в теле пакета `docs/v2` (в самом журнале остались названия
  филиалов, отделов и должностей гостиничной сети — они сохранены только как словарь
  предметной области и в продукт не переносятся).
- Формы документов, принятой в `docs/`: журнал написан по своей структуре (назначение →
  экраны → решения → гипотезы), а не по скелету из 15 секций. Переписывать его не нужно —
  это протокол наблюдения, а не требование.
