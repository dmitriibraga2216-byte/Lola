# Lola — дополнения по эталону Sintegrum

Этот репозиторий — **не полное ТЗ Lola**, а пакет **дополнений**, снятых с нового эталона
`brghotels.sintegrum.com` (LMS/ATS «Sintegrum», клиент BRG Hotels) поверх уже существующего
ТЗ Lola (снятого ранее с другого эталона — LMS Collaborator, bulochki.davintoo.com).

## Как читать

1. Начните с `docs/00-reference-inventory.md` — полная URL-карта эталона, журнал аудита,
   список того, что снято и что осталось непроверенным, и сводный список найденных
   дополнений.
2. Каждый следующий документ — один функциональный модуль, по единому скелету:
   назначение → экраны (снято дословно, с URL) → `[решение]` (наши архитектурные выводы) →
   `[гипотеза]` (что не удалось проверить, с «чем проверяется»).
3. `lola-additions-full.md` — все документы, слитые в один файл с оглавлением и якорями
   (для загрузки целиком в контекст модели или для печати).

## Статус

Аудит **не 100% исчерпывающий** — часть экранов эталона не открывалась (полный список — в
`00-reference-inventory.md`, раздел «Не закрытые разделы»). Все пробелы явно помечены
`[гипотеза]` с указанием, как их закрыть при повторном проходе. Ничего не выдано за
проверенное без проверки.

## Жёсткие ограничения, которые соблюдались при снятии

- Эталон — read-only: ничего не создано, не изменено, не удалено, формы не отправлялись.
- Учётные данные в чат не передавались, вход выполнил сам пользователь.
- Скопированы требования/логика/лейблы предметной области — не код, не вёрстка, не стили,
  не реальные персональные данные (кроме случаев, где это нужно как словарь предметной
  области — например, реальные названия филиалов/отделов/документов; ФИО и контакты живых
  сотрудников и кандидатов в документы не копировались).
